# Copilot Bridge

A native CLIProxyAPI plugin for GitHub Copilot subscription models.
The plugin owns upstream execution and preserves native Copilot protocol state.

The initial provider implementation derives from the MIT-licensed Copilot plugin v0.3.3.
See [NOTICE.md](NOTICE.md) for attribution and [PLAN.md](PLAN.md) for delivery scope.

Installation and verification instructions will be added with the validated artifact.
